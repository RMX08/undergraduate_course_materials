# 葡萄种植大棚物联网系统设计方案（概述）

## 一、设计目标

构建一套**低成本、易部署、可远程监控**的葡萄大棚物联网系统，实现大棚内环境（温湿度、光照、土壤墒情）实时监测、灌溉 / 通风 / 遮阳设备自动控制，同时支持数据可视化与远程管理，保障葡萄生长环境稳定，提升种植效率。

## 二、智能设备选择（感知 + 执行层）

1. **环境感知设备**：选用**Modbus-RTU 协议**的温湿度传感器、光照传感器、土壤温湿度 / 墒情传感器，采集大棚关键环境数据；搭配 CO₂传感器，监测棚内气体浓度。
2. **执行控制设备**：Modbus 协议继电器控制模块，对接**自动灌溉水泵、通风风机、遮阳电机、补光灯**，接收指令启停设备；选用支持 Modbus 的智能电表，监测设备用电。
3. **核心网关设备**：工业级物联网网关，支持 Modbus 协议转 TCP/IP，负责采集传感器数据、下发控制指令，实现设备与服务器的数据互通。

## 三、智能设备互连（网络层）

1. **底层互连**：所有传感器、继电器模块通过**RS-485 总线**组网，遵循**Modbus-RTU 协议**通信，统一接入物联网网关，布线简单、抗干扰强。
2. **网关与服务器互连**：网关通过以太网 / Wi-Fi 接入本地局域网，再通过**Modbus-TCP 协议**与云端 / 本地服务器通信，实现数据上传、指令下发，保障通信稳定。

## 四、编程语言选择（开发层）

1. **网关端**：选用**C 语言**开发网关底层程序，适配 Modbus 协议解析、数据采集与转发，运行高效、兼容性强。
2. **服务器端**：采用**Python**开发后端服务，利用其丰富的库快速实现数据接收、存储、分析，逻辑简洁、开发周期短。
3. **前端应用**：使用**HTML+CSS+JavaScript**开发 Web 管理界面，搭配 Vue 框架，实现数据可视化、设备远程控制，界面简洁易操作。

## 五、应用软件开发（应用层）

开发一套**葡萄大棚物联网管理系统**，核心功能如下：

1. **数据监测模块**：实时展示温湿度、光照、土壤墒情等数据，支持历史数据查询、趋势曲线生成。
2. **自动控制模块**：预设葡萄生长环境阈值（如温度 25-30℃），超标时自动触发风机、灌溉等设备；支持手动远程控制所有执行设备。
3. **告警管理模块**：环境异常、设备故障时，系统自动弹窗告警，保障及时处理。
4. **数据存储模块**：采用轻量数据库存储环境数据与设备日志，便于后续追溯与分析。

## 六、通信协议选择（Modbus 系列为主）

1. **底层设备通信**：采用**Modbus-RTU 协议**，基于 RS-485 总线，适配传感器、继电器等终端设备，成本低、可靠性高，满足短距离、多设备组网需求。
2. **网关与服务器通信**：采用**Modbus-TCP 协议**，基于以太网传输，实现网关与服务器的高速数据交互，支持远程访问与跨网络通信，适配物联网远程管理场景。

## 七、整体流程总结

**感知设备（采集数据，Modbus-RTU）→ RS-485 总线 → 物联网网关（协议转换）→ Modbus-TCP → 服务器（数据处理 / 存储）→ 前端应用（可视化 / 控制）→ 网关下发指令 → 执行设备（调节环境，Modbus-RTU）**，形成完整的 “感知 - 传输 - 处理 - 控制” 闭环系统。
